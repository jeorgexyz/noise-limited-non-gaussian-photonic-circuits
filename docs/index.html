Overview

Non-Gaussian resources — Fock states, cat states, cubic-phase and Kerr interactions — are what lift continuous-variable photonic circuits beyond efficient classical simulation. Physical noise degrades them. The practical question is not whether that happens but where the boundary sits, and whether the boundary for a nominal resource measure coincides with the boundary for operational usefulness.

Recent work indicates these are not the same thing: Wigner negativity can persist after it stops implying useful computational resourcefulness. This project distinguishes three quantities. Current experiments measure resource survival and task usefulness; classical simulation difficulty remains a planned axis.

$$\text{resource survival}\;\neq\;\text{task usefulness}\;\neq\;\text{classical simulation difficulty}$$

For a depth-$D$ circuit with imperfection channels $\mathcal N_l$,

$$\rho_{l+1} = \mathcal N_l\!\left[U_l(\theta_l)\,\rho_l\,U_l^\dagger(\theta_l)\right]$$

the advantage over the best resource-matched Gaussian circuit under noise configuration $\nu$ defines a collapse boundary:

$$A(D,\nu) = S_{\mathrm{NG}}(D,\nu) - S^{*}_{\mathrm{G}}(D,\nu), \qquad D^{*}(\nu) = \max\{D : A(D,\nu) > \epsilon\}$$

The Gaussian baseline is optimized under matched mean photon number, mode count, depth and measurement family. The comparison is against the best Gaussian circuit found under stated constraints, not against an arbitrary weak one.

Validated simulation core

Every quantity is checked against a closed form before it is used. The reference case is a single photon through a pure-loss channel of transmissivity $\eta$, which becomes $\eta|1\rangle\langle1| + (1-\eta)|0\rangle\langle0|$ with Wigner function

$$W(x,p) = \tfrac{1}{\pi}e^{-r^2}\left[2\eta r^2 - 2\eta + 1\right], \qquad r^2 = x^2+p^2$$

negative exactly where $r^2 < (2\eta-1)/(2\eta)$, so $\int|W| = 4\eta\,e^{-(1-\frac{1}{2\eta})} - 1$ for $\eta \ge \tfrac12$ and $1$ below. Wigner negativity of a lossy single photon therefore vanishes at exactly $\eta = 1/2$. One closed form exercises the channel, the Wigner transform and the negativity integral together.

Two numerical effects the validation quantifies

Truncation induces negativity in Gaussian states

By Hudson's theorem a pure state has a non-negative Wigner function iff it is Gaussian. A truncated, renormalised squeezed ket is not Gaussian, so it carries negativity that is numerical. At $r=1.0$, cutoff 20 this reaches $W_{\log}=0.063$ — 18% of a real single photon's 0.355.

Backend agreement is not always evidence

For the cubic-phase gate two independent backends agree to $10^{-17}$ while both differ from the converged result by $9.6\times10^{-5}$, identically. They exponentiate the same truncated $x^3$. Where implementations coincide, only cutoff convergence is informative.

Negativity does not discriminate

All three resources lose Wigner negativity at essentially $\eta = 1/2$, while their operational thresholds differ by a factor of about three. Fock $|1\rangle$ carries the least negativity and is the most robust on the task.

Decoupled in both directions

A lossy single photon has $W_{\log}=0$ below $\eta=1/2$ yet still beats the best matched Gaussian down to $\eta \approx 0.15$. For the other two, the Gaussian baseline wins outright below $\eta \approx 0.35$.

What bounds the claim

The target is a state the non-Gaussian circuit holds exactly, so $A > 0$ at high transmissivity follows by construction; what does not is how far down in $\eta$ the advantage persists. $S^{*}_{\mathrm{G}}$ is a lower bound on the true Gaussian optimum, which makes $A$ an upper bound — so $A < 0$ is the robust direction, and $A > 0$ carries convergence evidence, recorded per point as the converged fraction and start spread. The optimizer itself is checked against a brute-force grid search on the energy shell, agreeing to $2.4\times10^{-9}$, and against the analytic best-coherent value $1/e$ which it must exceed by using squeezing.

A second task reverses every verdict

The same resources, the same baseline construction, a different task: estimate a phase imprinted by $U(\theta)=e^{-i\theta \hat n}$, scored by the classical Fisher information under homodyne detection. This tests whether the decoupling above is a property of one task or of the resources.

The mechanism is exact rather than numerical. A Fock state is invariant under phase rotation, $e^{-i\theta \hat n}|n\rangle\langle n|e^{i\theta \hat n} = |n\rangle\langle n|$, so it carries no phase information under any measurement and its Fisher information is identically zero. Fock states tie at zero Fisher information even though they outperform the Gaussian preparation baseline on the first task. The negativity ranking does not consistently predict performance across these two tasks.

The baseline has a closed form here

For squeezed vacuum $\mathrm{Var}(n) = 2\bar n(1+\bar n)$, so $\mathrm{QFI} = 8\bar n(1+\bar n)$ and homodyne saturates it. The optimizer recovers exactly 16.0000 at $\bar n = 1$, with the optimum at pure squeezing and no displacement.

Energy matching must be exact

Fisher information grows monotonically with energy, so a soft-penalty baseline overspent its budget by ~15% rather than matching it. The baseline now uses energy-shell coordinates where the constraint holds identically.

Taken with the preparation results, this says operational usefulness is not a single axis. A resource measure that ranks these three resources predicts neither task.

Noise axes are resource-specific

Phase diffusion averages $U(\phi)=e^{-i\phi \hat n}$ over $\phi \sim N(0,\sigma^2)$, which has the closed form

$$\rho_{mn} \;\longrightarrow\; \rho_{mn}\,e^{-\sigma^2 (m-n)^2/2}$$

Diagonal elements are multiplied by $e^0=1$, so a Fock state is a fixed point: phase diffusion cannot reduce a Fock state's Wigner negativity at any $\sigma$, while it removes the interference fringes a cat state depends on. Which noise axis threatens a resource depends on the resource.

This channel also commutes exactly with pure loss, since loss Kraus operators preserve the Fock-index offset $m-n$ and phase diffusion depends on nothing else. A layered circuit built from these two alone collapses to a single $(\eta^D,\ \sigma\sqrt{D})$ channel, so depth is only an independent axis once a non-commuting element sits between layers. The experiment uses Kerr gates with partial loss. Lossless layers, complete loss, and Kerr strengths that reduce to ordinary phase rotations are handled separately.

Kerr depth collapse

Starting with squeezed vacuum at $r=0.6$, each layer applies Kerr strength $\xi=0.2$, loss, and phase diffusion. Both arms are scored by fidelity to the same noiseless target at each depth. The baseline optimizes a pure displaced squeezed input with matched energy and identical noise exposures, with all active Gaussian preparation at the input and no intermediate pumping.

The tail bound uses an explicit feasible Gaussian witness and applies to every future target. It does not certify the earlier Gaussian optima: the best score found is a lower bound, so positive advantage and D* remain optimistic estimates for the stated preparation family. Intermediate Gaussian controls and mixed Gaussian input states are outside that family. Under dephasing, a Gaussian-prepared output need not itself remain Gaussian.

Method

Two backends

A pure-NumPy reference backend runs the single-mode sweeps, with Piquasso 8.0.1 providing a separate implementation for cross-checks. Interleaved Kerr/loss trajectories are checked across both backends.

Closed forms first

Pure loss, Fock and coherent Wigner functions, the lossy-photon negativity integral and the phase-diffusion average all have analytic references used as tests.

Convergence enforced

The depth sweep checks NG fidelity at every depth with a larger cutoff. Boundary candidates also receive extra optimizer starts and Wigner grid checks. Reported thresholds carry a stated tolerance and numerical diagnostics.

Bounded scope

Results currently cover one mode. The planned extension is to 2–4 modes, where Fock dimension grows combinatorially.
